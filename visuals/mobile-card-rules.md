# 手机长图规则

长图用于把已经形成的结论和行动路径压缩成方便手机查看的视觉摘要，不替代正文建议。

## 支持的图形

| 类型 | 适用问题 | 必填数据 |
|---|---|---|
| `timeline` | 两周实验、30/90 天计划 | 时间点、行动 |
| `risk` | 婚前审计、安全风险 | 风险名称、等级、动作 |
| `responsibility` | 家务、育儿、照护 | 任务、负责人、复核日 |
| `cost` | 彩礼、婚礼、住房、债务 | 项目、金额 |
| `decision` | 推进、延期、退出分支 | 条件、下一步 |

## 版式与可访问性

- 画布使用 1080 像素宽的 SVG，内容较多时自动增加高度；
- 首屏先显示结论，再显示图表和下一步；
- 红色只表示停止或高风险，不能只靠颜色传达等级；
- 每个 SVG 必须包含 `<title>` 和 `<desc>`；
- 同时保留 Markdown/Mermaid 或表格回退；
- 不放姓名、手机号、地址、账号、私人照片和原始聊天。

## 输出边界

`tools/render_decision_visual.py` 只生成本地 SVG，不调用网络和图片模型。输入包含 HTML/SVG 字符时会转义。生成物默认放在用户指定目录，不自动加入公开知识库。
