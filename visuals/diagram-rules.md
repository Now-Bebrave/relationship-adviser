# Diagram rules

Use a visual when it materially improves understanding:

- more than two meaningful reaction branches;
- several time points or dependent steps;
- three or more options that need comparison;
- multiple people whose roles or influence are easy to confuse;
- an abstract family or relationship pattern that benefits from a diagram.

Prefer a Markdown table for comparisons and Mermaid for sequence, hierarchy, and reactions. Put the conclusion before the visual. Every diagram must have a text summary that preserves the same actions and branches.
