# Private vault

This directory is for local-only material: personal profile data, sensitive cases, decision history, knowledge notes, video notes, and source indexes. It is ignored by Git except for this README.

Keep original videos in the existing MediaCrawler directory. Store paths, hashes, timestamps, transcripts, and derived notes here when needed.

Voice transcripts and decision records are not saved by default. After explicit user consent, decision history may be stored under `decisions/`. A local `sync-manifest.json` may contain relative paths, sizes, and hashes for integrity checking; it must remain inside this ignored directory.
