# Relationship Adviser 知识库导航

## 目录

- `notes/`：研究卡片。每张卡记录题目、作者、DOI、证据状态、可用结论和外推限制。
- `playbooks/`：行动指南。按“结论—依据—步骤—话术—反应—停止条件—流程图”组织，适合直接回答具体困扰。
- `books/`：书籍元数据和使用边界。书籍观点先标记为背景材料，不替代同行评议研究。
- `legal/`：法律和官方流程资料。涉及彩礼、婚姻登记、财产、监护和安全时单独核对当地规则。
- `verified-sources.md`：公开来源登记表和核验深度。
- `rejected-sources.md`：撤稿、无法核验或不应复用的来源。

## 推荐加载顺序

1. 先读相关 `playbooks/`，确定问题类型和可执行步骤；
2. 再读对应 `notes/`，核对证据状态、适用范围和限制；
3. 涉及财产、登记、子女或人身安全时，同时读 `legal/`；
4. 书籍、博主和视频只作为背景或案例材料，必须与研究结论、现实核验和用户事实分开；
5. 具体个人案例、原始视频、抓取索引和决策历史只放在仓库外的 `private-vault/`，不进入公开提交。

## 输出要求

调用知识卡时，答案应区分事实、推断和未知，并给出详细步骤、可复制话术、对方可能反应、对应回答、停止条件和信息缺口。研究的群体关联不能写成个人诊断、性别定律或成功率。
