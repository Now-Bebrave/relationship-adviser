# 关系决策模板

这些模板用于把讨论变成可复核的记录。填写时只写必要事实，不复制身份证号、账号、住址、原始聊天或私人视频。金额使用同一币种，未知项写 `unknown`，不要用感觉补齐。

## 模板索引

| 模板 | 用途 |
|---|---|
| `premarital-total-cost.md` | 婚前总成本、彩礼、婚礼和住房 |
| `debt-and-cashflow-stress-test.md` | 收入、债务、失业和应急金压力测试 |
| `migration-90-day-trial.md` | 异地迁移、试住、工作和回程方案 |
| `mental-load-weekly-log.md` | 家务、照护和心理负荷记录 |
| `parent-care-time-money.md` | 父母照护时间、费用和决策权 |
| `childbearing-responsibility-plan.md` | 生育、育儿和备用支持 |
| `exit-logistics-and-safety.md` | 分手后的住房、财务、证件和安全路线 |

## 使用规则

1. 先分别填写，再共同核对，避免一方代替另一方作答。
2. 把事实、假设、承诺和待确认项分开。
3. 设置复核日期；临时新增条件视为新方案。
4. 出现威胁、暴力、经济控制或强迫时，停止普通协商，改用安全计划和专业支持。
