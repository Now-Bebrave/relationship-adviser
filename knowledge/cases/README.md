# 公开案例库

这里存放已经去标识化、可公开复核或明确标为训练模板的案例卡片。案例用于展示决策过程，不代表统计规律，也不能替代研究证据。

## 证据等级

- `L1`：公开事实或官方记录；
- `L2`：公开内容中的可追溯叙述，关键事实仍可能不完整；
- `L3`：观点型视频、个人经验或训练模板，不能外推到其他人。

当前 v1.4 新增卡片均为 `synthetic_training_template`，用于测试分流和回答结构，不冒充真实事件。收到用户授权且完成脱敏后，再将真实视频或案例替换为独立卡片。

未授权或含私人信息的材料只放在 `private-vault/cases/`，不进入公开案例库。
