# 主题分流协议

先判断问题属于哪个主类，再加载对应指南和研究。一个问题可以有多个标签，但最多选择一个主类作为第一入口，避免把所有知识卡一次性塞进回答。

## 分流表

| 主类 | 触发词或事实 | 首先加载 | 必须核对 |
|---|---|---|---|
| 择偶与吸引 | 外貌、吸引、筛选、暧昧、要不要继续 | `appearance-attraction-and-body-respect.md`、承诺与择偶指南 | 吸引是否稳定、价值观、尊重和安全 |
| 冲突与修复 | 吵架、冷战、道歉、反复犯错 | 冲突/修复 playbook | 具体行为、频率、修复是否持续 |
| 同居与承诺 | 同居、订婚、登记、结婚 | `premarital-cohabitation-audit.md` | 财务、住房、家务、生育和退出成本 |
| 彩礼与婚房 | 彩礼、婚礼、房产、三金、借款 | 彩礼、支付审计和法律资料 | 用途、产权、债务、付款证据 |
| 家庭边界 | 父母、婆媳、岳父母、断供、催婚 | 家庭边界、父母介入指南 | 伴侣是否共同执行边界 |
| 迁移与照护 | 异地、辞职、回乡、养老、照护 | 迁移路线图、照护负荷审计 | 谁承担时间、钱、职业机会和失败后果 |
| 生育与育儿 | 要不要孩子、备孕、育儿、产后 | 生育意愿、育儿和心理负荷指南 | 自愿、健康、时间、分工和备用支持 |
| 性与健康 | 性需求、同意、避孕、性病 | 性自主、健康和通知指南 | 持续同意、医疗信息和人身安全 |
| 金钱与控制 | 查账、上交工资、担保、限制工作 | 经济控制和财务安全指南 | 能否自由拒绝、是否有威胁或报复 |
| 退出与安全 | 分手、威胁、跟踪、暴力、自伤 | 关系退出、家暴和安全指南 | 立即危险、住处、证件、支持网络 |

## 调用规则

1. 先读取主类 playbook，再读取最多 3 张最相关研究卡。
2. 若出现控制、暴力、强迫、未成年人或急性自伤风险，安全指南优先于沟通指南。
3. 资料不足时先列出缺失信息，不用最相似的案例替代事实。
4. 研究只支持群体层面的关联；个人建议必须标注推断和不确定性。
5. 回答结束前检查是否包含结论、步骤、反应、停止条件和备选路径。
