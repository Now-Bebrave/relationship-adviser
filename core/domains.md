# 领域模块

## 收录主线与优先级

知识收录以亲密关系生命周期和高频情侣/婚姻问题为主线：

1. **认识与确定关系**：筛选、吸引、邀约、关系确认、投入节奏和线上约会；
2. **稳定交往**：沟通、冲突、嫉妒、信任、性与边界、双方家庭和日常分工；
3. **同居、订婚与结婚决策**：财务、彩礼、见家长、生育、住房、家务、法律和风险审计；
4. **婚后长期协作**：情绪劳动、育儿、照护、睡眠、职业变化、亲密维护和关系复盘；
5. **危机与退出**：背叛、暴力、胁迫、成瘾、重大冲突、修复、分居和安全退出。

其他领域只有在直接改变伴侣互动、婚姻决策或安全边界时收录；每条资料必须能转化为具体步骤、话术、反应分支或停止条件。

按问题调用一个或多个模块：

- 恋爱开始与推进；
- 吸引、投入和关系节奏；
- 冲突、冷战、信任与修复；
- 见家长、彩礼和婚前协商；
- 婚姻分工、财务、生育和双方家庭；
- 性、欲望差异、边界和亲密沟通；
- 分手、复合和关系退出；
- 个人成长、社交能力和长期生活规划；
- 关系心理学：吸引、选择、承诺、依赖、权力和修复；
- 人格与情绪：Big Five、依恋、焦虑、回避和情绪调节；
- 认识与约会：第一次见面、体验设计、邀约、关系确认和线上约会；
- 沟通策略：聊天分析、场景校准、倾听、共情、赞美、冲突、道歉和拒绝；
- 社交策略与 PUA：机制拆解、风险识别、防御和低风险替代；
- 性学与亲密：持续同意、性沟通、欲望差异、避孕、健康边界和身体自主；
- 婚姻与家庭：婚前协商、共同财务、家务、生育、双方父母和家庭生命周期；
- 法律与安全：婚姻家庭法律、家暴、跟踪、诈骗和证据保存；
- 社会与人文：婚姻变迁、人口、城市化、平台约会、性别分工和照护劳动；
- 恋爱哲学：欲望、友爱、自由、承诺、共同体、自我与他者、爱与占有；
- 分手与特殊情境：失恋、背叛、复合、信任重建、多元关系和反刻板印象。

MBTI 只用于沟通偏好和自我反思，不用于给人定性或预测伴侣适配。
