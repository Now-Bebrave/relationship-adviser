# 语音交互协议

语音只是输入和输出通道，不能改变证据、隐私和安全规则。

1. ASR 输出先转为文字草稿，保留 `source=voice` 和识别语言；低置信度、金额、日期、姓名及否定词必须向用户复述核对。
2. 在用户确认前，不根据可能误识别的彩礼金额、债务、用药、暴力或生育信息作不可逆建议。
3. 回答先生成完整文字版，再生成适合朗读的短版；朗读版不得省略停止条件和紧急路径。
4. 没有可用 ASR/TTS 时直接回退到文字，不伪造转写或音频。
5. 语音、转写和决策日志默认只用于当前对话。只有用户明确要求保存，才写入 `private-vault/`。
6. 公开仓库不得保存用户音频、私人转写、声纹、联系人或设备标识。

## 朗读版结构

- 一句话结论；
- 今天要做的 1–3 步；
- 对方最可能的反应和一句回应；
- 停止条件；
- 提醒用户查看文字版中的证据与详细表格。
