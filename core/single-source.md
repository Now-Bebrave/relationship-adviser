# 单一知识源协议

所有平台必须加载同一套共享资料，不允许在适配器目录复制或维护独立知识库。

## 公共资料源

- 根入口：`SKILL.md`
- 核心规则：`core/`
- 研究与指南：`knowledge/`
- 视觉规则：`visuals/`
- 平台适配器只负责调用方式，不得改写研究结论或另建来源清单。

本地开发以仓库根目录为唯一源。Codex 和 Claude Code 可以通过目录联接直接读取该目录。WorkBuddy 手机版以 GitHub `main` 为公共源，仓库发布后通过更新或重新导入同步。

## 私人资料边界

`private-vault/` 仅在用户明确授权且平台能访问本机目录时加载。私人档案、案例、语音、决策日志和原始媒体不得通过公开 GitHub 同步到 WorkBuddy。

## 更新顺序

1. 在仓库根目录补充资料；
2. 运行全量测试与包校验；
3. 提交并推送 GitHub；
4. Codex 和 Claude 的目录联接立即读取本地版本；
5. WorkBuddy 执行更新/重新导入，确认 `adapters/manifest.json` 版本一致。
