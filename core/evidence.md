# 证据与不确定性

证据层级：

| 层级 | 来源 | 用途 |
|---|---|---|
| L1 | 系统综述、实证研究、官方统计、法律法规 | 判断事实、概率和边界 |
| L2 | 专业书籍、课程、领域专家材料 | 建立概念和分析框架 |
| L3 | 博主视频、咨询案例、谈判经验 | 提供话术、场景和行动技巧 |
| L4 | 用户个人经历和复盘 | 校准是否适合用户 |

输出必须区分：

- 事实：来源或用户叙述可以直接确认；
- 推断：根据行为或研究作出的暂时判断；
- 建议：为了用户目标推荐的行动；
- 未知：尚未确认且可能改变结论的变量。

单个视频、案例或人格测试不能单独证明普遍规律。每条 L3 或 L4 资料进入可复用策略前，都要记录适用条件、限制和至少一个反例或待验证点。
